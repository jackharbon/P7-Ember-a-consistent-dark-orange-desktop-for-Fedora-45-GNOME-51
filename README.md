# P7-Ember-a-consistent-dark-orange-desktop-for-Fedora-45-GNOME-51
A personal, dark-only GNOME theme set built around one idea: the whole system should look like one design, from the boot menu to the third-party apps. Soft-3D surfaces, flat faces, one orange accent (#F5732A), smoked-glass popups and a topographic "Ember Layers" wallpaper.
